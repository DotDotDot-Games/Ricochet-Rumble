# Ricochet-Rumble

Ricochet Rumble is 2-player a shooter game with a retro aesthetic unlike the rest. You have to bounce your bullets to kill your opponent!

In other words, if you shoot directly at them, the bullets will bounce back toward you!

![Ricochet Rumble][ricochet-rumble1.png]
 
## How to Play

Player 1:

* Keyboard:
- WASD: Move
- O: Shoot
- P: Stand still
- Pick up weapon: Don't move for 1 second
* Controller:
- Left Joystick: Move
- L2: Shoot
- L1: Stand still

Player 2:

* Keyboard:
- Arrow keys: Move
- X: Shoot
- P: Stand still
- Pick up weapon: Don't move for 1 second
* Controller:
- Right Joystick: Move
- R2: Shoot
- R1: Stand still
